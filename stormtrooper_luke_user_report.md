# Stormtrooper Luke — proponowana optymalizacja modów

**Zakres:** wyłącznie Stormtrooper Luke i dawcy z zatwierdzonego łańcucha.  
**Stan celu w eksporcie:** 4★, G12, 0/6 modów.  
**Podstawa:** udany przebieg walidacji GitHub Actions nr 43735251561, snapshot raportu z commita 20a3215b917c0f2cc15b7866528794b2b9b3a410.  
**Wynik:** wykonalny łańcuch 25 przekładek; kompromis dla rosteru, nie automatyczna zgoda na wykonanie.

## 1. Cel i profil docelowy

Najczęstsza kombinacja profilu SWGOH.GG dla Stormtrooper Luke'a to **Speed + Health** — 60,1% kompletnych buildów.

- Priorytety secondary: Speed, Health, Protection, Offense.
- Najczęstsze primary: Arrow — Speed (94,67%); Triangle — Protection (55,96%); Circle — Protection (69,54%); Cross — Protection (56,14%).
- Źródła profilu: Top 1000 Kyber GAC (945 kompletnych buildów) oraz Top 100 Guilds (4858 kompletnych buildów).

Proponowany build zachowuje kombinację setów Speed + Health, ale nie wszystkie primary odpowiadają najczęstszym wyborom profilu. To istotny kompromis, opisany przy slotach.

## 2. Sześć slotów Stormtrooper Luke'a

Wszystkie sloty celu są obecnie puste. Poniżej podaję pełny opis każdego proponowanego moda, jego aktualne miejsce i powód wyboru.

- **Obecny mod Luke'a:** brak — pusty slot.
